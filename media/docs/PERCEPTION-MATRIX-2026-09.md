# 媒资感知能力全景矩阵（2026-09-06）

> 配套：模型选型见 MODEL-PICKS-2026-09.md ｜ 素材见 MEDIA-TEST-MANIFEST.md
> 原则：**检测交给小模型，理解交给 VL，精识按需触发**——VL 不做逐帧哨兵

## 一、四层级联架构

```
L1 逐帧轻量检测（毫秒级，全量帧/抽帧）
   镜头切割 │ 人脸检测 │ 文字检测(OCR-det头) │ 技术QC(黑场/彩条/静帧/失焦/抖动)
        ↓ 命中才触发
L2 每镜头 VL 理解（关键帧 1-3 张）
   场景语义描述 │ 场景分类 │ 涉政要素(标语/地图/旗帜/领导人) │ 复杂文字兜底
        ↓ 专用任务
L3 专用精模型（按需调用）
   OCR识别(PP-OCRv5/v6) │ 人脸比对(face_library) │ 声纹比对 │ 地标/旗帜细分类
L4 音频独立线（与视频并行）
   VAD → ASR(Qwen3-ASR) → 说话人分离(CAM++)+词级对齐(ForcedAligner)
        → 音频事件(掌声/音乐/静音) → 响度/音画同步(QC)
        ↓
   汇聚：每镜头一条 JSON（时间码+全部维度）→ 编目库(M5) → 检索(M9)
```

| 转场类型（切/叠/淡） | 切割器特征+规则 | |

### 技术监测 QC（废镜头判定）
| 能力 | 方法 | 判定 |
|---|---|---|
| 黑场/彩条/静帧/坏帧 | 帧差+颜色直方图（经典广电 QC） | 废镜头硬标准 |
| 失焦 | 拉普拉斯方差 | 废镜头 |
| 过曝/欠曝/噪点 | 直方图+噪声估计 | 废镜头 |
| 镜头抖动 | 光流稳定度（全局运动矢量方差） | 稳定器素材标记 |
| 音画同步 | ForcedAligner 时间戳 vs 口型/音频帧偏移 | 广电硬指标 |
| 响度超标 | EBU R128（-23 LUFS ±） | 广电硬指标 |
| 分辨率/码率/封装核对 | ffprobe 属性比对 | 入库必检 |

### 审校辅助（辅助人工三审，非自动拦截）
| 要素 | 方法 |
|---|---|
| 领导人画面/出场与职务顺序 | 人脸库比对 + ASR 文本人名顺序校验 |
| 标语/口号文字准确性 | OCR + 文本比对（VL 兜底） |
| 地图完整性（疆藏台标） | 地图检测模板比对 |
| 国旗/党旗使用规范 | 旗帜细分类 + 规则 |
| 敏感词/违禁词 | ASR 文本 + OCR 文本过词表 |
| 涉政画面要素 | VL 要素清单问答 |
