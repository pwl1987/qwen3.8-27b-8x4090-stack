# lb/ — OpenResty 动态负载均衡（本仓库核心贡献之一）

多副本 llama-server 的生产级路由方案：`qwen27b.conf`（入口 :8000 + /_lbstats + 监控路由）
+ `route.lua`（核心逻辑）。

## 五机制

1. **会话粘滞**：key=请求体前 512B，TTL 30min 命中续期 → 前缀 KV 命中率最大化
2. **粘滞不漂移**：大会话漂移=每轮冷 prefill 更糟；仅满载/不健康才漂
3. **接最闲健康副本**；池占用 ≥POOL_HI 不接新会话
4. **大小会话分流**：请求体 >600KB（≈130K+ token）→ r2/r3 大会话池
5. **软摘除**：DISABLED 文件 drain（全禁用时忽略防自锁）；负载探测 2s 缓存

验证口径：48 路并发全成功 + 粘滞/漂移/新会话计数在 /_lbstats。
